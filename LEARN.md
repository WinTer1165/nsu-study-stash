# 📚 How to use NSU Study Stash (Study Guide)

A short guide to getting the most out of this archive — whether you're starting your NSU CSE journey or cramming for a final.

---

## 1. How the materials are organized

Every course downloads as **one zip**. Inside, files are pre-sorted so you never have to dig:

| Folder | What's in it |
|--------|--------------|
| `Course Info/` | Outline, calendar, office hours, course objectives |
| `Lectures/` | Slides and lecture notes (the main study material) |
| `Assignments/` | Assignment briefs + an `Assignments.md` summary for some courses |
| `Projects/` | Project files, reports, presentations — and **GitHub links** where a repo exists |
| `Exams & Quizzes/` | Midterms, finals and **previous-semester questions** |
| `Labs/` | Lab manuals + working code (bundled inside the parent course for 115/215/231) |
| `Books & References/` | Textbooks, solution manuals, research papers |
| `README.md` | Per-course overview: modules, faculty, and assignment list |

> Start with the `README.md` inside each zip — it's the table of contents for that course.

## 2. A suggested CSE roadmap

The order most NSU CSE students follow, and what each course leans on:

```
Year 1   CSE115 → CSE115L    (C basics)        + MAT116 / MAT120
         CSE173              (logic & proofs — feeds 225 & 373)
Year 2   CSE215 → CSE215L    (Java / OOP)       + MAT125
         CSE225              (data structures — the big one)
         CSE231 → CSE231L    (digital logic)    + EEE141
Year 3   CSE311              (databases)
         CSE323              (operating systems)
         CSE327              (software engineering — group project heavy)
         CSE332              (computer architecture)
         CSE373              (algorithms — pairs with 225)
Year 4   CSE331              (microprocessors / embedded)
         CSE438              (computer networks)
         CSE468 / CSE482     (electives: NLP / web tech)
```

**Dependencies worth knowing**
- **CSE225 (Data Structures)** depends on solid C/Java (115/215) — don't skip the basics.
- **CSE373 (Algorithms)** builds directly on 225 and the proof techniques from 173.
- **CSE332 (Architecture)** is smoother after 231 (digital logic).
- **CSE331 (Embedded)** assumes you're comfortable with C and digital logic.

## 3. Study tips for exams

1. **Previous questions first.** Open `Exams & Quizzes/` and work the past mids/finals before re-reading slides — NSU question patterns repeat a lot.
2. **Slides over textbooks.** Faculty exams track the lecture slides; use the books in `Books & References/` only to fill gaps.
3. **Run the lab code.** For 115/215/225/311/331, reading code isn't enough — compile and break it.
4. **Check the project repos.** Linked GitHub projects show a full, working example of what the course is building toward.
